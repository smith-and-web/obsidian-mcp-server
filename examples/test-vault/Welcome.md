## Getting Started

Use this vault to test the various MCP tools:

1. **Read operations**: Try reading this note or others
2. **Create operations**: Create new notes in the Inbox folder
3. **Tag operations**: Add or remove tags from notes
4. **Search**: Search for "project" or "meeting"
5. **Links**: Find backlinks to this note
